# debug_coordinates.py

## Description
This script is designed for debugging the coordinate transformations of markers. It loads marker coordinates from a CSV file, simulates the transformations applied in the main detection script (swapping, expanding dimensions, and applying offsets), and prints the results at each step. This helps in verifying that the coordinate manipulations are correct.

## When to use this
Use this script when you are unsure about the marker coordinate transformations and want to verify that the final coordinates used by the application are correct. It's useful for debugging issues related to marker detection and alignment.

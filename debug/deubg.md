# deubg.py

## Description
This script is a debugging tool designed to diagnose and explain common errors in the corner detection logic. It loads a static image and marker data from a CSV file, then attempts to crop a sub-image around a specified corner. The script includes detailed print statements that explain corrections for common errors, such as incorrect file handling and NumPy array slicing, making it an educational tool for understanding the codebase.

## When to use this
Use this script when you are encountering fundamental errors in the corner detection pipeline and need to understand the root cause. It is especially helpful for debugging issues related to file I/O, data parsing, and basic image manipulation, as it provides explicit explanations for common pitfalls.
